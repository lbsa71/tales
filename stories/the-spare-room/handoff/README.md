## Status

This is a development handoff for a complete first draft once working terms are agreed. The excerpts are exploratory and do not join directly. The latter movements and provisional ending remain to be scripted. The runtime and performance conventions have not been tested in a reading.

The latest feedback prompted only two preparatory repairs: distinguish temporary shared perception from continuing residence, and make Ruth's change of intention follow from the successful quiet trial. The other three concerns are questions for the writing and reading, not prerequisites for another proposal.

The snapshot's manifest lists file sizes and SHA-256 digests. The build's visual inspection checks readability of the packet; it does not validate the drama.
