# First-draft baseline - The Spare Room

Preserved before the second-draft rework on 22 September 2026.

- [Nine-movement manuscript](chapters/README.md): the exact first-draft chapter files.
- [Continuous reading copy](the-spare-room.md): the compiled first-draft Markdown.
- [First-draft PDF](the-spare-room.pdf): the existing reading PDF, copied without rebuilding it.
- `development/`: exact snapshots of the top-level project Markdown before the rework. Their relative links retain their original project context; use the current project index for navigation outside this archive.
- [Manifest](MANIFEST.json): original byte sizes and SHA-256 digests for all the captured files. This explanatory README was added after capture and is not part of that manifest.

The archive is historical and should not be updated to agree with later decisions. A repository attribute disables line-ending conversion in this directory so the captured byte hashes survive checkout on other systems. The [current manuscript](../../chapters/README.md) is maintained separately. Swedish translation and audio remain based on this first draft until a translation revision is commissioned.
